	certificates + key
		seemingly theres places you can get that generated and signed - online maybe ? yes
		its also possible to make your own, but its less browser-compatible w/out a CA and setting one up is long
	solution ::
		put the certificate and key in an environment variable(s)
		in Dockerfile, RUN echo "$SSL_CERT" "$SSL_KEY" > /nginx_cert/name_here.crt
		then RUN chmod 040 || 400 (unsure)
	openssl to create a certificate ::
		first, install openssl ::
			update + upgrade
			apt install openssl
		first, password-protected RSA key, 2048bit, encrypted ::
			openssl genrsa -des3 -out [domain].key 2048
			enter password when asked
		then, aquire a certificate signing request ::
			openssl req -key [domain].key -new -out [domain].csr
			enter necessary info, put '.' for blank -> Common Name should be the exact domain name
		finally, use both to obtain a self-signed certificate ::
			openssl x509 -signkey [domain].key -in [domain].csr -req -days 365 -out [domain].crt
